# inpx-web — add-on для Home Assistant

Обёртка над [inpx-web 1.5.8](https://github.com/bookpauk/inpx-web) (форк `drts-sv/inpx-web`):
поиск по `.inpx`-коллекции fb2 + веб-интерфейс + OPDS-сервер для читалок.

## Что внутри

| Файл | Зачем |
|---|---|
| `config.yaml` | манифест add-on: опции, порт, монтирование `media`/`share` |
| `Dockerfile` | Debian bookworm (glibc — бинарник pkg собран под glibc, не под musl) + готовый релизный бинарник под `amd64`/`aarch64` |
| `run.sh` | читает опции из `/data/options.json` через `jq`, находит `.inpx`, генерирует `config.json`, запускает сервер |

## Установка

1. Скопировать папку `inpx_web` в `\\homeassistant\addons\` (через Samba NAS).
2. В HA: **Настройки → Дополнения → Магазин дополнений → ⋮ → Проверить обновления**.
3. Открыть появившийся «inpx-web library», вкладка **Конфигурация**, проверить `lib_dir`.
4. **Установить** (Supervisor соберёт образ локально, 1–3 мин), затем **Запустить**.

Веб-интерфейс: `http://<ip-ha>:12380/` — кнопка **OPEN WEB UI** в карточке add-on,
плюс отдельная панель «Библиотека» в сайдбаре.
OPDS: `http://<ip-ha>:12380/opds`.

## Опции

| Опция | По умолчанию | Смысл |
|---|---|---|
| `lib_dir` | `/media/disk/torrents/fb2.Flibusta.Net` | каталог с `.inpx` и zip-архивами; смонтирован **только для чтения** |
| `inpx_file` | пусто = автопоиск | если в каталоге несколько `.inpx` — указать явно |
| `data_dir` | `/data/inpx-web` | поисковая БД, кэш, логи, `config.json`. Персистентный том |
| `access_password` | пусто = без пароля | пароль на веб-интерфейс (WS-авторизация с солью) |
| `opds_user` / `opds_password` | пусто | Basic-auth для OPDS |
| `low_memory` | `true` | `lowMemoryMode` в конфиге — на этом HA swap уже загружен, оставляем включённым |

## Известные ограничения (осознанные)

- **Без ingress.** inpx-web отдаёт статику от корня сайта, ingress с префиксом
  `/api/hassio_ingress/<token>/` даёт 404. Поэтому порт 12380 + Open Web UI.
  Снаружи — проброс порта на роутере или через тот же туннель/DDNS, что и HA.
- **Первый старт долгий**: строится поисковая БД по `.inpx`. Для Flibusta это
  десятки минут и заметная нагрузка на CPU/RAM. Последующие старты — секунды,
  т.к. `/data` переживает обновления add-on'а.
- Каталог библиотеки — **ro**. Если нужна запись (например, `bookReadLink` с
  сохранением), меняйте `map: media: read_only: false` в `config.yaml`.
- Архитектуры: `amd64`, `aarch64`. На `armv7`/`i386` релизных бинарников нет.
- Тип `password` в опциях хранится в `/data/options.json` в открытом виде —
  как и в оригинальном `config.json`.

## Откат

Удалить add-on в UI, удалить папку `\\homeassistant\addons\inpx_web`,
данные (БД) — `/data/inpx-web`, чистятся только с удалением add-on с данными.
